  1. Content area

    The content box is the area that the content lives in. The content can control the size of its parent, so this is usually the most variably sized area.

  2. Padding area

    The padding box surrounds the content box and is the space created by the padding property. Because padding is inside the box, the box's background is visible in the space it creates. If the box has overflow rules set, such as overflow: auto or overflow: scroll, the scrollbars also occupy this space.

  3. Border area

    The border box surrounds the padding box, and its space is defined by the border value, which creates a visual frame for the element. The element's border edge is the limit of what you can see.

  4. Margin area

    The final area, the margin box, is the space around your box, defined by the box's margin rule. Properties such as outline and box-shadow occupy this space too because they're painted on top of the element and don't affect the size of the box
Because the CSS uses the default box-sizing: content-box, the applied width is the width of the content, and padding and border on both sides are added to that
SELECTORS

We have multiple types to select an element or group of elements as follows:

  • Universal Selector
    * {
     color:red
    }
    This rule causes every HTML element on the page
  • Type Selector
    section {
     color:red
     padding: 2em;
    }
    A type selector matches a HTML element directly
  • Class Selector
    .my_class {
     color:white
     padding: 2em;
    }
    Any element that has the class applied to it, you can put multiple css classes
  • ID Selector
    #my_id {
     color:white
     padding: 2em;
    }
    An HTML element with an id attribute should be the only element on a page with that ID value. avoid applying styles with the id selector as it means you can't re-use those styles elsewhere
  • Attribute Selector
    [data-type='primary'] {
     color:white
     padding: 2em;
    }
    You can look for elements that have a certain HTML attribute, or have a certain value for an HTML attribute by wrapping the selector with square brackets ([ ])
    [data-type] {
     color:white
     padding: 2em;
    }
    Instead of looking for a specific value of data-type, you can also look for elements with the attribute present, regardless of its value.
    [data-type='primary' s] {
     color:white
     padding: 2em;
    }
    case-sensitive attribute selectors by adding an s operator to your attribute selector. case insensitivity attribute selectors by adding an i operator to your attribute selector. Along with case operators, you have access to operators that match portions of strings inside attribute values.
  • Grouping Selectors
    strong, em, section, .my_class, #my_id, [lang] {
     color:white
    }
